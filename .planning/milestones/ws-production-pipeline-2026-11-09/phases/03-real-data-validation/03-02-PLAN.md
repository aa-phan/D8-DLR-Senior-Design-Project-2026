<objective>
Get the real data: the owner runs the backfill over the stated window through the cleaned pipeline,
and the executor proves the run is complete and records it for Phase 4.

Purpose: ROADMAP success criterion 1 (a stated real window of at least 14 days, all four cities,
window and command recorded) and the input to VAL-01/VAL-02. The executor cannot read `.env`
(secret-read guard) and the backfill needs SYNOPTIC_TOKEN, NREL_API_KEY and NREL_API_EMAIL, so the
run itself is the owner's, at a human-action checkpoint. It must run in the main checkout, because
the per-city models (`data/models/forecast_{CITY}.joblib`, `anomaly_{CITY}.joblib`) are git-ignored
and exist only there.

Window choice (planner's discretion; the owner may change it at the checkpoint within the limits
stated there): 2026-09-08T00:00Z to 2026-09-28T23:00Z.
- Out of sample: the C9/C10 models were trained 2026-10-13 on complete calendar years 2023-2025
  (`forecast_training.fetch_city_weather`, `FORECAST_ML_TRAINING_YEARS = 3`), so a 2026 window is
  not in their training data.
- Production-like inputs: NSRDB has no 2026 data, so solar comes from Open-Meteo or the Synoptic
  station exactly as on the live path; Synoptic's Open Access tier covers the last year.
- Clear of the shadow evaluation: it ends before 2026-09-29, the anti-peeking cutoff used by the
  confirmation protocol, and before the frozen 2026-09-30..10-04 experiment frames.
- As late as those limits allow, so the history Phase 4 loads (DB-03) is as close to go-live as it
  can be; the remaining gap to go-live is a Phase 4 input recorded in the report.
- 21 days, not 14: the archive starts empty, so the first week builds the history the ml band and
  the detector need (12 rows for a forecast, 24 for the rolling baseline). The 14 scored days that
  follow measure the steady state Phase 4 will start from.
- Within OD-8: the live path reads the last 30 days of history per city, so a 21-day archive is
  read whole at every step, as the live path will read its own window.

Output: the git-ignored archive, trace, log and console files in the main checkout; the committed
`manifest.json` and `run_completeness.csv`.
</objective>
