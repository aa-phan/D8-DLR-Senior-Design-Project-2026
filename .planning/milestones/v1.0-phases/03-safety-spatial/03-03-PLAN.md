<objective>
Make the corridor rating survive real-world data loss: broaden station discovery past the WTM network,
probe candidate stations nearest-5-then-10 per point, and fall back to the static rating when a point
runs out of usable data — then prove the weakest-span logic with the bottleneck test C8's spec asks for.

Purpose: DS-F10 and DS-NF5. D-06's live access check found Synoptic returns usable data for only 25 to
75 percent of candidate stations depending on the city, so a single-nearest-station lookup would leave
Corpus Christi and Midland corridors dark most of the time. This plan turns that measured unreliability
into a bounded, fail-safe probe rather than an exception, and closes the last ROADMAP Success Criterion
2 case: a corridor point that cannot be trusted resolves toward the static rating.

Output: a corridor rating that is correct when data is available, conservative when it is not, and
never dependent on a token appearing in a log line.
</objective>

discretized into multiple weather-sampling points.
