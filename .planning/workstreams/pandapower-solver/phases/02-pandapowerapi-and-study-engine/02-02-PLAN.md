Create `backend/pandapower_job/api.py` (Python 3.12; may import `psse_job` and `pandapower_job`; `psse_job` never imports it, per D-01). Module docstring: what the adapter is (the same methods the study code uses from PsseApi, over a pandapower network built by `network.build_network`), the state machine, the outcome mapping table of RESEARCH Pattern 3, that messages never hold a bus number, branch key or value, that the case is read only by the project's own fail-closed parsers (never pandapower's own network serialisers or Python object serialisation), and assumption Q2 (RAW or converted JSON by suffix).

Define `PandapowerBackend = collections.namedtuple("PandapowerBackend", ["solve_settings", "scaling_details"])`; `class PandapowerCallError(psse_api.PsseCallError)` whose `__init__(self, function, ierr, meaning)` sets the three attributes and calls `RuntimeError.__init__(self, "pandapower.%s failed: ierr=%s (%s)" % (function, ierr, meaning))`; state names `FRESH`, `SOLVED`, `FAILED`, `STALE`.

`PandapowerApi.__init__(self, backend, protected_path=None)`: refuse anything that is not a `PandapowerBackend` with `ValueError("backend must be a PandapowerBackend")`; `self._backend`; `self._protected` normalised with `psse_api._normalise_path` (None stays None); `self.warnings = []`; `self._masters = {}` (normalised path to the built network); `self._snapshots = {}`; `self._net = None`; `self._state = FRESH`; `self._last_reason = None`.

`load_case(self, path)` (case-file part; snapshots come in Task 2): normalise the path; if no master is cached for it, read at most the size cap plus one byte (`convert.MAX_CONVERTED_BYTES` when the normalised path ends with `.json`, else `raw.MAX_RAW_BYTES`); an `OSError` raises `PandapowerCallError("load_case", 3, psse_api.CASE_ERRORS[3])`, an oversized file `PandapowerCallError("load_case", 2, psse_api.CASE_ERRORS[2])`; parse with `convert.case_from_json` for `.json`, else `raw.parse_raw`, then `network.build_network`, and cache the result (parser and builder refusals are ValueError subclasses and pass through unchanged). Set `self._net = copy.deepcopy(master)` and the state to `FRESH`. The master is never handed out or changed.

`branch_table(self)`: needs a loaded net (`PandapowerCallError("branch_table", None, "no case is loaded")` otherwise); lines from `net.line` with `ckt = name.split("-", 2)[2]` and the name's bus parts checked against `from_bus`/`to_bus` (`"branch name does not match its buses"` otherwise), `in_service` from the table, `is_transformer` False; transformers from `net.trafo` (`hv_bus`, `lv_bus`), skipped when the key is already a line, as PsseApi does; a repeated key raises `"duplicate branch key"`; both lists sorted by key. Allowed in every state.

`read_rate(self, ref, rate_set)`: validate `rate_set` against `psse_api.RATE_INDEX` with PsseApi's exact text, take the parts with `psse_api.PsseApi._ref_parts(ref)`, find the line by its key in either orientation; a transformer key or a missing branch raises `PandapowerCallError("read_rate", 2, psse_api.BRNDAT_ERRORS[2])`; return `max_i_ka * sqrt(3) * vn_kv` of the line's own `from_bus`. Every rate set reads the one limit. Allowed in every state.

`set_rate(self, ref, rate_set, mva)`: the same validation, in the same order and with the same texts, as `PsseApi.set_rate` (rate set, number, out of range, finite above 0), then the parts; a transformer raises `PandapowerCallError("set_rate", 3, psse_api.BRANCH_CHNG_ERRORS[3])`, a missing branch `PandapowerCallError("set_rate", 9, psse_api.BRANCH_CHNG_ERRORS[9])`; write `max_i_ka = mva / (sqrt(3) * vn_kv of from_bus)` (the rating becomes a current limit per circuit, D-07); state `STALE`.

`solve(self, options=None)`: any `options` that is not None raises `ValueError("solve options are PSS/E fnsl options and are not supported by pandapower; use null")`; needs a loaded net; `settings = self._backend.solve_settings`; call `solve.run_load_flow(self._net, settings, settings.enforce_q_lims)` through the module attribute (so tests can observe it; D-06: settings come from the backend, never from a constant in this module); if it raises ValueError set the state to `FAILED` and re-raise. Map the outcome (keep `self._last_reason = outcome.reason`, never an exception message): converged gives `psse_api.classify_solve(0, 0, outcome.iterations, None)` and state `SOLVED`; reason "nan_voltage" gives `classify_solve(3, None)`; "voltage_collapse" gives `classify_solve(0, 2)`; any other reason gives `classify_solve(0, 1)`; all three set state `FAILED`. Return the SolveResult; non-convergence is a result, never an exception.

`branch_loading(self, rate_set, basis)`: validate both with `psse_api.pct_string(rate_set, basis)`; a basis other than "current" raises `ValueError("thermal basis mva cannot be reproduced by pandapower; use current")` (D-07); require state `SOLVED` through a helper `_require_solved(function)` that raises `PandapowerCallError(function, None, "no valid solution (state: %s)" % self._state)`; for every line build `BranchFlow(from_bus, to_bus, ckt, in_service, rate_mva = sqrt(3) * vn_kv(from_bus) * max_i_ka, pct = res_line.loading_percent, p_mw = res_line.p_from_mw, max_mva = max(hypot(p_from_mw, q_from_mvar), hypot(p_to_mw, q_to_mvar)))` with floats, `in_service` from `net.line` (never from the results), sorted by key; lines only.
