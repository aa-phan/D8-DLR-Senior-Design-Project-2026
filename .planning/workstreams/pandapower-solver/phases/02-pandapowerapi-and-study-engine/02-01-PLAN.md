**Deviation in form from D-02, for the owner to confirm (not blocking).** D-02 says "a plain string (`\"psse\"` default, `\"pandapower\"`)". A literal mapping of `"pandapower"` to `pandapower_job.api` inside `study.py` fails the existing gate `test_imports_stay_inside_the_laptop_boundary` (any non-allow-listed import is flagged, even inside a function, and `importlib` is not on the allow-list). So the string is resolved through `API_FACTORIES`; `pandapower_job.api` registers its factory under `"pandapower"` when it is imported (plan 02-03). The caller still passes one plain string, the default is still `"psse"`, and `psse_job` stays free of the second solver (D-01). Reversibility: reversible (a callable factory could be added later without breaking the string).
</objective>
