<objective>
Build the spine of the laptop session (PSE-01): one command that loads PSS/E the way the job does, checks the mapping against the case, exports the network as RAW text written by PSS/E itself, collects every output in one work folder, writes one verified zip, deletes the mapping copy and its own folder, and prints a masked summary. The section table is in place for the reference answers (plan 01-03) and the settings and scaling experiments (plan 01-04), which plug in as modules without editing this plan's files.

Purpose: the session is expensive to repeat (D-05) and most of its calls have never run on PSS/E 36.4. This plan makes the session survive its own unverified calls (section isolation, candidate export forms), stay read-only by construction (a call gate plus runtime proofs), and leak nothing in what is pasted back.
Output: `backend/psse_session/` (`__init__.py`, `session.py`, `bundle.py`), `backend/psse_pandapower_session.py`, `backend/tests/psse_session_fake.py`, `backend/tests/psse_session_test.py`.
</objective>
