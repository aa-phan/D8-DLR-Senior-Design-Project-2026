## Who does what

- The user (this machine, push rights): holds `data/private/pandapower/`, so runs `bundle`, `scan-log` and the local comparison; can dispatch workflows (`gh workflow run`), list runs and download logs.
- The owner, Aaron (admin): merges to main, creates secrets and the variable, creates the cron-job.org job and its token, holds the writer connection string, runs the size query in the Supabase SQL editor.
- Nobody writes a secret value, token, password, connection string or private figure into a message, an issue, the repository or a resume message. Resume messages carry printed vocabulary lines, counts, dates and words only.
