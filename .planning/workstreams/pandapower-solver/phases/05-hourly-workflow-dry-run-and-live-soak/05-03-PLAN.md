## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dispatcher (cron-job.org token, a collaborator) to the workflow | anyone who can dispatch picks a ref, never an input |
| branch content to the `production` environment's secrets | a branch could edit the workflow |
| GitHub-hosted runner to pip and the action registry | third-party code runs with the secrets in the environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-10 | Elevation of privilege | a branch that edits the workflow to print secrets | high | mitigate | job `if: github.ref == 'refs/heads/main'` plus the `production` environment's main-only branch policy (verified live in research); secrets stored at environment level; text test pins the guard |
| T-05-11 | Tampering | a dispatcher choosing live mode | high | mitigate | no `inputs:` at all; the switch is only `vars.PANDAPOWER_LIVE`; text tests forbid inputs and any other source of the switch |

| T-05-13 | Tampering | third-party action tampering | low | accept | only `actions/checkout@v4` and `actions/setup-python@v5`, the same first-party actions as `dlr_live.yml`; `persist-credentials: false` |
