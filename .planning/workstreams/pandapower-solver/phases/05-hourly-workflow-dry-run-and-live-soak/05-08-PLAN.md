## Rules for this plan

| ID | Rule |
|----|------|
| R-1 | The flip happens only after Task 1's greps pass on a go-live answer. A stay-dry answer ends the plan after Task 1. |
| R-2 | Records hold printed lines, counts, sizes, dates and words only: no run id of the result tables, hash, secret, connection detail or private figure. |
| R-3 | The soak verdict is recorded as printed. A missed hour restarts the count; nothing is back-filled, re-run or relabelled to reach 24 (D-04). Manual dispatches are avoided during the soak (each adds a permanent row set, research Pitfall 7). |

## Timing (research Pattern 6)

The gap check never walks the current hour, so 24 slots first show on the run in the hour 24 hours after the first live run (the 25th run). The first live slot is the UTC hour in which the first `mode: live` run started (read from `gh run list --workflow pandapower_hourly.yml`, the run's start time floored to the hour), not the time the variable was set.
