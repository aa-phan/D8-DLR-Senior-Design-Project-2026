### What the port does (public API, for Session B's Task 4)

- `run_confirmation(*, cities, guard_cfg, evidence_root, protocol_status="unsigned", now=None, params=None, frame_provider=None, model_loader=None, window=None, repo_root=None, extra_probe_arms=None) -> report`. Order: scope valid times from the window; `check_guard(row_source="reconstructed_frames")`; refuse a development-basis run without an injected `model_loader` (ValueError, before the evidence directory exists); `new_evidence_dir`; per city provider, prepare, load models, predict, leakage probe; errors; metrics; `build_family_report`; `apply_ship_rule`; provenance; `write_report`.
- `window` is `(scored_start, scored_end_exclusive)` or a `ScoredWindow`; default is `2026-09-30T00Z .. cutoff` (192 slots). The guard receives the six-hourly scored-window slots (2026-09-30T00Z..2026-11-16T18Z), not the 2026-09-28 fetch start, so a FRESH run is classified FRESH and an injected development window is classified development (Session A note 1). A custom window requires an injected `frame_provider` (ValueError otherwise).
- `frame_provider(city, *, evidence_dir) -> (frame, archive_weather, meta)`. `production_frame_provider` builds the frame through `anchored_pair_frame(city, 2026-09-28, 2026-11-16, lead_hours=24)` inside `record_http(evidence_dir, city)` with `config.FORECAST_EXPERIMENT_CACHE_DIR` set to `evidence_dir/frames` (restored in a `finally`), refusing any other window and any pre-existing cache file, and re-parses the recorded archive body into the full hourly truth weather. A Task 4 injected development provider must return `archive_weather` whose rows equal the frame's `truth_*` columns bit-for-bit at every scored hour (the port raises `ReconstructionError` on any difference, including `relative_humidity`) and must include the lead-in hours for the reference features (anchor minus 6 h).
- `model_loader(city, method)`; default `forecast_shadow_pipeline.load_correction_model` (FRESH only). A `FileNotFoundError` becomes `candidate_unavailable` for that candidate with its text kept in `diagnostics[city].unavailable_reasons`.
- `prepare_city_frame(frame, city, *, window=None) -> (prepared, diagnostics)`, `candidate_predictions(prepared, archive_weather, city, models, *, unavailable=None) -> (DataFrame, diagnostics)`, `leakage_probe(prepared, city, models, *, extra_arms=None)`, `load_models`, `dry_run(...)`, `main(argv)`.
- The output frame of `candidate_predictions` is indexed by valid_time with `truth_amps`, the five candidates and one `<candidate>__excl` reason column each (`candidate_unavailable`, `candidate_failed`, `reference_features_missing`).
