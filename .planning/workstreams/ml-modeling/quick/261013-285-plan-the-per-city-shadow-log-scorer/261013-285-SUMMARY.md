1. **[Process] Tests written alongside the implementation, not RED-first with separate RED commits.** The plan marks both tasks `tdd="true"`.    - `backend/forecast_shadow_eval_core.py` got a one-word edit in Task 2 (MDD column header).
3. **[PD-15 reading] Where an override is required.** A non-default instant or cutoff needs `--override-reason` regardless of basis (literal reading of the Task 1 behaviour list). A non-default pre-registered statistical parameter needs it only in a FRESH run (PD-15 text). This lets development-basis tests and rehearsals use `n_resamples=300`.
4. **[PD-10 reading] "Cities with data".** A city has data when it has at least one paired row (point margin not None). A wind-vs-alternative comparison whose pooled outcome is `insufficient_data` (fewer than 8 pooled paired rows) can never qualify as "consistently better". The plan text does not say the second part explicitly; it follows from "insufficient data" being a valid level and avoids a 1-row alternative displacing the default.
5. **[S3 detail] Headline "inconclusive" reason.** `block_length_sensitive` when the smallest p over the runs is at or below 0.05/9 but the maximum is not (the "significant only at L = 1" construction); otherwise `crosses_zero`.
6. **[S3 detail] Two-stage cluster scheme uses the global slot grid for each drawn city** (blocks of L consecutive slots, rows of that city inside the drawn slots), so L runnability is `L <= S/2` for both pooled schemes.
7. **[Fetch window] The archive `end_date` is clamped to the day before the cutoff day** (`end_date` strictly before the cutoff day). Reference targets at or after the cutoff are a candidate-level exclusion (`reference_target_at_or_after_cutoff`), not fetched.
8. **[Guard scope] Reference target hours enter the guard's scope valid times only for rows whose reference candidate is cleanly usable and whose target is before the cutoff.**
9. **[Exclusion taxonomy] Truth exclusions are row-level** (`truth_fetch_failed`, `truth_missing`, taken at the logged valid hour). `reference_target_truth_missing` is candidate-level for the reference only. The accounting identities hold per city (`accounting` block in `exclusions`, asserted in tests).
10. **[Evidence dir] A same-second second run raises `FileExistsError`** (refused, not merged), in addition to the one-shot marker rule.
11. **[Test design] Independent-cities ESS test uses the default block lengths and asserts a ratio in [3.0, 5.0]** (about 4x, within 25%). Empirically the ratio was 4.07 for (1, 4) and 4.00 for (1, 4, 8, 28) at n = 150 per city.
12. **[Test design] The block-length-sensitivity constructions differ per test** (per-city uses a mean of 2.5 on a sinusoid of amplitude 10; pooled uses 5.0), tuned so that the interval excludes 0 at L = 1 and not at L = 28. The first per-city value (5.0) did not produce sensitivity at 120 rows.
