## Design decisions adopted from research (planner-locked)

| ID | Decision used here |
|----|--------------------|
| D-11 | Thermal basis `current` (default) or `mva` via MAXPCTRATEx or MXPCTMVARATx of the first rate set; limit_value = rating x thermal_limit_pct / 100; observed_value = pct / 100 x rating; a rating of 0 (no limit) is skipped. Voltage limits from configuration (default) or the case (EVLMLO/EVLMHI after an outage, NVLMLO/NVLMHI for the base); isolated buses (type 4) skipped. |
| D-12 | Manual single-line outage loop (not ACCC); contingency_id and branch element_id are "from-to-ckt" in the case orientation; the outaged line is not evaluated in its own contingency; a non-converged outage is one non_convergence row and counts as a contingency with results; caps fail the stage. Transformer, generator and multi-element outages are not screened (stated in plan 02-07's definitions note). |
| D-14 | Reload the saved base before every outage; never un-trip and re-solve. |
| in_base_case | A row's details.in_base_case is true when the same element already violated its pre-contingency limit of the same kind in the solved base (thermal: the same rating limit; voltage: base_low_pu/base_high_pu, or NVLMLO/NVLMHI with source case); details.base_value carries the base value so a reader can apply another rule. |
