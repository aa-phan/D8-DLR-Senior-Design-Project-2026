| ID | Decision used here |
|----|--------------------|
| D-08 | Mapping check before any write; all problems in one message; accept the reversed orientation by normalising to the case's; transformers and mixed base kV are mapping failures. |
| D-09 | kV is the from-bus base kV read from the case; one base kV per city; the DLR MVA goes to every listed rate set; read back to 1e-6 relative; record the case's previous rating (`rate_before_mva`) for Power Systems to see (open question 5, not resolved here). |

| D-14 | Save the solved base once to a temp file and reload it before every later evaluation; never save onto the case path. |
