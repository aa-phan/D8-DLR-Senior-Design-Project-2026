1. `clock` defaults to `datetime.now(timezone.utc)`; take `started_at = clock()` once (a naive value raises ValueError before anything else: a programming error).
2. `context = RunContext(new_run_id(started_at), started_at, case_label(case_id), case_sha256, mapping_sha256, job_version(env))`.

4. Call `study(selection, context)` once inside try/except Exception; on an exception set `failure = failure_from_exception("internal", exc)` (a StudyFailed keeps its own stage) and keep no results.
5. Without a failure, call `validate_results(results, selection)`; a ResultsInvalid sets `failure = Failure("validate_results", <redacted message>)` and drops the results (an invalid set is never written).
6. `finished_at = max(clock(), started_at)`.
7. `record = build_run_record(context, selection, finished_at, results=<results or None>, failure=failure)`.
8. Only now call `connect()` (D-04: nothing touches the database earlier); any exception -> log the redacted message and return status "not_recorded", exit EXIT_NOT_RECORDED.
9. With a failure: `record_failure(conn, record)` -> status "failure_recorded" (or "already_recorded"), exit EXIT_FAILED_RECORDED; RecordFailed -> "not_recorded", EXIT_NOT_RECORDED.
