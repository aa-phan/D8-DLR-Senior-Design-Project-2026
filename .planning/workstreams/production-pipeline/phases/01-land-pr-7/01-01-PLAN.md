backend/backfill_archive.py
- `backfill(start, end, step_hours=1.0, archive_path=DEFAULT_ARCHIVE, log_path=DEFAULT_LOG, cities=None, forecast_method="naive", skip_synoptic=False, stations=None, fetcher=None, out=print) -> dict`
  - totals keys: `runs`, `skipped` (ints); `archived`, `not_archived`, `fallback`, `exhausted`, `gates`, `errors` (Counters); `provider_issues` (dict), `sources` (dict of dicts).
  - Calls the module-level name `run_dlr_pipeline(cities=todo, end=ts, window_hours=1.0, provider="composed", forecast_method=..., archive=True, archive_path=..., stations=..., fetcher=...)` once per step that has cities left; the step's stdout is redirected into a buffer and `_GATE_RE = r"\b(G[1-6]) FAIL"` counts gates in it.
  - Step skip: `done = _already_archived(archive_path)` is read ONCE at the start; `todo = [c for c in cities if ts not in done.get(c, set())]`; an empty `todo` adds 1 to `skipped`.
  - Log row per summary city: `f"{ts},{city},{rating_a:.1f},{fallback},{exhausted},{archived},{'|'.join(fallback_gates)},"`; per error: `f"{ts},{city},,,,,,{msg.replace(',', ';')[:120]}"`. `ts` uses `%Y-%m-%dT%H:%M:%SZ`. Flushed after every step.
  - `except KeyboardInterrupt:` calls `out("\nInterrupted -- progress is saved; rerun the same command to continue.")` and returns the totals.
  - DEFAULT_ARCHIVE and DEFAULT_LOG point into the repository's data and outputs directories: every test passes `archive_path` and `log_path` under tmp_path.
- `_LOG_HEADER = "run_end_utc,city,rating_a,fallback,exhausted,archived,gates,error"`
- `_retire_stale_log(log_path)`: missing or empty file -> no-op; first line != `_LOG_HEADER` -> `os.replace(log_path, log_path + ".legacy")`.
- With `fetcher=None`, backfill builds `observation_composer.make_composed_fetcher(stations, field_priority=...)`, dropping "synoptic" from every field when `skip_synoptic=True`.

backend/observation_composer.py (the stub seams)
- Calls `weather_provider.fetch_weather([stid], start, end, provider="synoptic", fallback=False)`, `tceq_provider.fetch_tceq(cams_id, start, end)`, `nsrdb_provider.fetch_nsrdb(lat, lon, start, end)`, `open_meteo_provider.fetch_open_meteo(lat, lon, start, end)` through its module references, so `monkeypatch.setattr(oc.weather_provider, "fetch_weather", stub)` (and the three others) is the seam.
- Runs whose `end` is more than `HISTORICAL_AFTER_DAYS` (2) days old request whole UTC days from TCEQ/NSRDB/Open-Meteo (`end` becomes `...T23:59:59Z`). Stub frames must therefore carry FIXED `datetime_utc` values, never ones derived from the `end` argument (a probe that did so put TCEQ's rows after `end`, and the composer correctly skipped TCEQ).
- TCEQ is only used when the station is within `TCEQ_MAX_KM` (50 km) of a city in `config.CITY_COORDINATES` (AUSTIN maps to CAMS "38").
- Provider frames need a `datetime_utc` column plus the field columns (`air_temp`, `wind_speed`, `wind_direction`, `solar_radiation`); speed only counts with a direction from the same provider and hour.

backend/city_rating.py
- `rate_city(...)` archives with `datetime_utc = end` (the run's end string), which is what `_already_archived` compares against.
