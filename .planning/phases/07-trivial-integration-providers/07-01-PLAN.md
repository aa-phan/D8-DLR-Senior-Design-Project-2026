<objective>
Close WX-02: make every existing station-path `fetch_weather` call transparently return ASOS
1-minute wind/temp rows unioned into the Synoptic series, in `PIPELINE_SCHEMA` units, with each
row's provenance naming the provider that actually supplied it.

Purpose: this is the phase's proof that Phase 6's adapter design works. Phase 6 built the
provenance, city-resolution and merge seams against a synthetic grid provider; this plan is the
first time a real second provider plugs into them. If the seams are wrong, they are wrong here, on
one vertical slice, before Open-Meteo (Plan 07-02) and NSRDB/TCEQ (Phases 8-9) are built on top.

Output: `config.ASOS_STATIONS`; a new `backend/asos_provider.py` fetch-and-normalize module;
`_supplement_with_asos` wired into `_fetch_station`'s `provider="synoptic"` branch; test coverage
for the happy path, the unit conversions, the fail-loud paths and the outage carve-out.
</objective>
