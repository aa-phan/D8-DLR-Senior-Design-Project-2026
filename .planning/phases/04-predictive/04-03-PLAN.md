<objective>
Finish C10: give the detector a cold-start path so it works before a forecast exists, resolve its
control limit per location the way Phase 3 learned to, and wire it plus the archive write into the
real corridor entry point — then pin the dependency set so any of this is reproducible.

Purpose: ROADMAP Phase 4 Success Criteria 3 and 4, and requirement DS-F12. Plan 04-01 proved a G6 trip
reaches the static rating through the one fallback helper; what is missing is the detector actually
being reachable from the system's real entry point, and a baseline that works on the day the archive
is still nearly empty. The per-location multiplier is the part with history behind it: Phase 3 shipped
a single global `RATING_BOUNDS` band, discovered it was incompatible with three of four cities, and
had to replace it with a per-location dict. This plan will not repeat that.

Output: an `AnomalyDetector` with both a forecast-residual signal and a rolling-baseline cold start,
a `rate_corridor` that archives one row per run and accepts an injected detector, a `requirements.txt`,
and tests proving a synthetic anomaly falls back while clean data never does.
</objective>
