# v1.1 Multi-Provider Weather — Shipped 2026-09-15

**5 phases (6–10), 15 plans, 37 tasks.**

## What shipped

- **Adapter redesign.** `weather_provider.py::fetch_weather` now accepts either a station-ID
  list or a `(lat, lon)` grid tuple through one type-dispatched `location` parameter, with zero
  breaking changes to any existing caller. `PIPELINE_SCHEMA` v3 added four per-field provenance
  columns (`wind_source`, `temp_source`, `humidity_source`, `solar_source`).
- **ASOS + Open-Meteo (Phase 7).** ASOS 1-minute wind/temp rows transparently supplement every
  Synoptic station-path call. Open-Meteo's Archive API became the grid path's first real
  implementation, returning all five weather variables from a single request — closing WX-04.
- **NSRDB solar (Phase 8).** NREL NSRDB PSM v4 became the primary solar-irradiance source
  (`solar_radiation` with `nsrdb` provenance), with per-year window decomposition for ranges
  crossing a calendar-year boundary and credential-redacted error handling — closing WX-03.
- **TCEQ CAMS (Phase 9).** TCEQ CAMS became the primary wind/temp/RH source for all four cities
  via real HTML-report scraping, serving any window up to 31 days via per-local-calendar-day
  decomposition. A live check of all four CAMS sites found and fixed two real report-parsing
  bugs no mocked test could have caught.
- **Synoptic as automatic fallback (Phase 10).** Synoptic now auto-retries a failing or empty
  TCEQ/NSRDB request (station and grid paths both), with honest provenance and a WARNING audit
  log — never triggered by a caller-shaped error or a missing-credential `EnvironmentError`.
  Confirmed end-to-end against the live Synoptic and NSRDB endpoints: all four
  `SYNOPTIC_FALLBACK_STATIONS` return real data (three of which had never been fetched under this
  project's token before).
- **Documentation ratified (Phase 10).** `PRD.md` §7.1 and `data_provider.md` now record the
  shipped five-provider composition as the team's ratified decision, closing the project's
  longest-standing open engineering item and correcting the System Design Report's self-flagged
  NOAA/NSRDB discrepancy.

## The shipped composition

| Variable family | Provider | Provenance value |
|---|---|---|
| Wind speed/direction, temperature, RH | TCEQ CAMS (primary) + ASOS 1-minute (supplement) | `tceq` / `asos` |
| Solar irradiance (GHI) | NREL NSRDB PSM v4 | `nsrdb` |
| Full set, historical bulk backfill | Open-Meteo Archive API | `open_meteo` |
| Any of the above, on primary failure | Synoptic (automatic fallback only) | `synoptic` |
